# Предварительные требования

В этой главе описаны знания, оборудование и программное обеспечение, которые необходимы для прохождения курса.

## Rust

Требуется определённый опыт работы с Rust и программирования в целом. Этот курс не ставит целью научить программированию или самому языку Rust, поскольку для этих тем уже существует много качественных материалов.

Если вы совсем не знакомы с языком, мы рекомендуем сначала прочитать [The Rust Book] (на английском языке). Также можно заранее ознакомиться с [The Rust on ESP Book], хотя это и не обязательно.

[the rust book]: https://doc.rust-lang.org/book/
[the rust on esp book]: https://esp-rs.github.io/book/

### Тулчейн

Требуется последняя стабильная версия тулчейна Rust, а также нужно установить целевую платформу `riscv32imc-unknown-none-elf`.

Rust следует устанавливать с помощью официального установщика, который находится по адресу <https://rustup.rs/>. Необходимые тулчейн и целевую платформу можно установить командой:

```shell
rustup toolchain install stable --target riscv32imc-unknown-none-elf
```

## Дополнительное ПО

Для загрузки прошивки на устройство мы также будем использовать [espflash]. Его можно установить с помощью Cargo:

```shell
cargo install espflash --locked
```

[espflash]: https://github.com/esp-rs/espflash

## Оборудование

В этом курсе мы будем использовать отладочную плату [ESP32-C3-DevKit-RUST-2]. Можно использовать и другие платы, но эта плата содержит датчики и другие устройства, которые используются нашим приложением, поэтому для наилучших результатов настоятельно рекомендуется использовать именно её.

Проектные файлы этой отладочной платы (схемы и т. п.) доступны в репозитории [esp-rs/esp-rust-board]. Плату можно купить на AliExpress и Mouser, см. раздел [Где купить].

[esp32-c3-devkit-rust-2]: https://github.com/esp-rs/esp-rust-board
[esp-rs/esp-rust-board]: https://github.com/esp-rs/esp-rust-board
[где купить]: https://github.com/esp-rs/esp-rust-board#where-to-buy
