# Игра «Змейка»

Теперь мы реализуем простую игру [«Змейка»](https://en.wikipedia.org/wiki/Snake_(video_game_genre)), в которую можно играть на MB2: светодиодная матрица 5×5 служит экраном, а две кнопки — органами управления. Попутно мы будем опираться на понятия из предыдущих глав этой книги, а также познакомимся с новой периферией и новыми концепциями.

## Модульность

Исходный код здесь модульнее, чем, вероятно, следовало бы. Такая мелкая модульность позволяет разбирать код понемногу. Мы будем строить код снизу вверх: сначала создадим три модуля — `game`, `controls` и `display`, а затем соберём из них итоговую программу. У каждого модуля будет главный файл и один или несколько подключаемых файлов: например, модуль `game` состоит из `src/game.rs`, `src/game/coords.rs`, `src/game/movement.rs` и т. д. Для объединения частей модуля используется оператор Rust `mod`. В книге *The Rust Programming Language* есть хорошее [описание] системы модулей Rust.

[описание]: https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html
