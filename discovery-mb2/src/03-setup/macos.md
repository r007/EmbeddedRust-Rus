# macOS

Все инструменты можно установить через [Homebrew]:

[Homebrew]: http://brew.sh/

``` console
$ # Отладчик GDB: версия из brew собрана для всех архитектур, включая все встраиваемые ядра ARM
$ brew install gdb

$ # Minicom
$ brew install minicom

$ # lsusb выводит список USB-портов
$ brew install lsusb
```

Вот и всё! Переходите к [следующему разделу](verify.md).
