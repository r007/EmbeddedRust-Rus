# Жуткое действие на расстоянии

`OUT` — не единственный регистр, который управляет пинами порта `P0`. Регистр `OUTSET` тоже позволяет менять значения пинов, как и `OUTCLR`. Однако `OUTSET` и `OUTCLR` не позволяют узнать текущее состояние выходов порта `P0`.

Регистр `OUTSET` описан в [спецификации продукта]:

> Подраздел 6.8.2.2. «OUTSET» — стр. 145

Посмотрим на программу ниже. Ключевая её часть — `fn print_out`. Эта функция выводит текущее значение `OUT` в консоль `RTT` (`examples/spooky.rs`):

``` rust
{{#include examples/spooky.rs}}
```

Если запустить эту программу, увидите следующее:

``` console
$ cargo embed
# консоль cargo-embed
(..)
15:13:24.055: P0.OUT = 0x000000
15:13:24.055: P0.OUT = 0x200000
15:13:24.055: P0.OUT = 0x280000
15:13:24.055: P0.OUT = 0x080000
15:13:24.055: P0.OUT = 0x000000
```

Побочные эффекты! Хотя мы многократно читаем один и тот же адрес и не меняем его сами, значение меняется каждый раз, когда производится запись в `OUTSET` или `OUTCLR`.
