# Модуль вектора

Насколько сильно магнитное поле Земли? Согласно документации к методу [`magnetic_field()`], значения `x`, `y`, `z`, которые мы получаем, выражены в нанотеслах. Значит, чтобы получить величину магнитного поля в нанотеслах, нужно вычислить только модуль трёхмерного вектора, который описывают наши значения `x`, `y`, `z`. Как вы, возможно, помните из школы, он равен:

``` rust
use libm::sqrtf;
let magnitude = sqrtf(x * x + y * y + z * z);
```

[`magnetic_field()`]: https://docs.rs/lsm303agr/1.1.0/lsm303agr/struct.Lsm303agr.html#method.magnetic_field

В `core` у Rust нет математических функций для чисел с плавающей точкой, таких как `sqrtf()`, поэтому наша программа `no_std` должна взять их реализацию откуда-то. Для этого мы используем крейт [libm].

[libm]: https://crates.io/crates/libm

Соберём всё это в программу (`examples/magnitude.rs`):

``` rust
{{#include examples/magnitude.rs}}
```

Запустите её командой `cargo run --example magnitude`.

Программа выводит величину (силу) магнитного поля в нанотеслах (`nT`) и миллигауссах (`mG`, где 1 `mG` = 100 `nT`). Величина магнитного поля Земли лежит в диапазоне от `250 mG` до `650 mG` (она зависит от географического положения), так что в идеале вы должны увидеть значение примерно в этом диапазоне. Ваше значение, скорее всего, будет заметно отличаться, потому что датчик не откалиброван: о калибровке см. [приложение 3]. После калибровки у меня получается величина около `340 mG`.

[приложение 3]: ../appendix/3-mag-calibration/index.html
