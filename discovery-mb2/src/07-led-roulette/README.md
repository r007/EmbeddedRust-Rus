Работать с выводами светодиодов по отдельности довольно утомительно (особенно если, как здесь, нужны почти все), поэтому можно воспользоваться BSP-крейтом `microbit-v2`, о котором говорили ранее, и работать со светодиодным «дисплеем» MB2. Это выглядит так (`examples/light-it-all.rs`):

```rust
{{#include examples/light-it-all.rs}}
```

Массив Rust `light_it_all` из примера содержит 1 там, где светодиод горит, и 0 там, где он выключен. Вызов `show()` принимает таймер, который код дисплея BSP использует для задержек, *копию* массива и время в миллисекундах, в течение которого показывается этот узор, прежде чем функция вернёт управление.
