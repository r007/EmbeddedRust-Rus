# Знакомство с программным обеспечением

В этой главе мы научимся собирать, запускать и отлаживать несколько *очень* простых программ. Цель — не углубляться в детали программирования MB2 на Rust (пока), а просто освоить сам процесс.

Сначала короткое пояснение об условных обозначениях, которые используются в остальной части книги. Предполагается, что вы получите копию всей книги с помощью команды:

```
git clone https://github.com/r007/EmbeddedRust-Rus/tree/main/discovery-mb2
```

«Исходный код» книги находится в `discovery-mb2/mdbook/src`. Зайдите туда в своей копии и осмотритесь. В каталоге каждой главы есть и исходный текст в Markdown, *и* полный исходный код всех программ этой главы. Когда мы упоминаем путь вида `src/main.rs`, имеется в виду место относительно главы, с которой вы работаете. Например, в вашем `discovery-mb2` есть файл `mdbook/src/05-meet-your-software/examples/init.rs`. В этой главе мы будем называть его просто `examples/init.rs`.

Есть два основных вида кода на Rust: исполняемые программы («binary») и библиотечный код («library»). Библиотечный код в этой книге большой роли играть не будет. Исходный код исполняемых программ может находиться в одном из нескольких мест:

* Программа в `src/main.rs` будет автоматически собрана и запущена командой `cargo embed` или `cargo
  run`. Специальные флаги не нужны.

* Программу в `examples/foo.rs` можно собрать и запустить командой `cargo embed --example foo` или
  `cargo run --example foo`.
  
* Программу в `src/bin/bar.rs` можно собрать и запустить командой `cargo embed --bin bar` или
  `cargo run --bin bar`.

Это может запутать, но это стандартное соглашение Cargo.

Теперь перейдём к делу и поработаем со всем этим.
