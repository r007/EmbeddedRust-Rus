# UART

Наш микроконтроллер (как и большинство) содержит периферийные устройства UART («Universal Asynchronous Receiver/Transmitter», универсальный асинхронный приёмопередатчик). На MB2 есть два вида UART: старый `UART` и новый `UARTE` («UART with Easy DMA», UART с простым DMA). Для связи с аппаратным последовательным портом мы будем использовать периферию `UARTE`.

На протяжении этой главы мы будем использовать последовательную связь, чтобы обмениваться информацией между микроконтроллером и вашим компьютером.
