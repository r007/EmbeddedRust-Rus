# Приём одного байта

Пока что мы умеем отправлять данные с микроконтроллера на компьютер. Пора попробовать обратное: принимать данные с компьютера (`examples/receive-byte.rs`).

``` rust
{{#include examples/receive-byte.rs}}
```

По сравнению с программой отправки байта изменилась только часть — цикл в конце `main()`. Здесь мы используем функцию `serial.read()`, чтобы дождаться доступности байта и прочитать его. Затем выводим этот байт в нашу отладочную консоль RTT, чтобы проверить, действительно ли данные поступают.

Обратите внимание: если вы прошьёте эту программу и начнёте печатать символы в `minicom`, чтобы отправить их микроконтроллеру, в консоли RTT вы увидите только числа: мы не преобразуем полученный `u8` в настоящий `char`. Поскольку преобразование из `u8` в `char` довольно простое, оставлю эту задачу вам, если действительно хотите видеть символы в консоли RTT.
