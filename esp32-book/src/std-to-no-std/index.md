# От std к no_std

Мы успешно прошили и запустили первую программу, которая мигает светодиодом. Однако код и структуру проекта мы пока подробно не разбирали. В этом разделе мы создадим тот же проект с нуля, а не через шаблон. По ходу дела я объясню каждую часть кода и конфигурации. Готовы к испытанию?


## Создание нового проекта

Начнём с создания обычного бинарного проекта Rust. Используйте следующую команду:

```rust
cargo new std_to_no_std
```

На этом этапе проект будет содержать привычные файлы:

```sh
├── Cargo.toml
└── src
    └── main.rs
```

Наша цель — получить следующую структуру проекта:

```sh
├── build.rs
├── .cargo
│   └── config.toml
├── Cargo.toml
├── rust-toolchain.toml
├── src
│   ├── bin
│   │   └── main.rs
```
