# Задержка


Одного переключения состояния светодиода между High и Low недостаточно. Если делать это без задержки, светодиод будет мигать так быстро, что вы этого даже не заметите. Чтобы мигание было видно, между переключениями нужна короткая пауза.

Добавьте необходимый импорт:
```rust
use esp_hal::time::{Duration, Instant};
```

Вот как это можно сделать:

```rust

loop {
    led.toggle();
    blocking_delay(Duration::from_millis(500));
}
```

Функцию задержки определим так:

```rust

fn blocking_delay(duration: Duration) {
    let delay_start = Instant::now();
    while delay_start.elapsed() < duration {}
}
```

Функция `blocking_delay` просто ждёт в цикле, пока не пройдёт заданное время. Она использует `Instant::now()`, чтобы запомнить время старта, и затем постоянно проверяет, сколько времени прошло. Это называется busy wait, или blocking delay (блокирующая задержка), потому что ЦП застревает в цикле и в это время не может делать ничего другого. Такой способ не самый эффективный, но он прост и хорошо подходит для быстрых тестов, например для мигания светодиодом.
