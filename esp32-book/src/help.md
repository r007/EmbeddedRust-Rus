# Помощь и устранение неполадок

Если вы столкнётесь с ошибками, багами или другими проблемами при выполнении упражнений, вот несколько способов разобраться с ними.

## 1. Сравните с рабочим кодом

Проверьте полные примеры кода или клонируйте эталонный проект для сравнения. Внимательно просмотрите свой код и версии зависимостей в `Cargo.toml`. Ищите синтаксические и логические ошибки. Если нужная feature не включена или есть несовпадение features, обязательно включите нужные, как показано в упражнении.

Если вы нашли несовпадение версий, либо адаптируйте код под новую версию (поищите решение сами: это отличный способ лучше разобраться в материале), либо обновите зависимости до тех версий, которые используются в руководстве.

## 2. Поищите или создайте issue на GitHub

Посмотрите страницу issues, чтобы проверить, не встречалась ли кому-то та же проблема:
[https://github.com/r007/EmbeddedRust-Rus/issues?q=is%3Aissue](https://github.com/r007/EmbeddedRust-Rus/issues?q=is%3Aissue)

Если нет, создайте новое issue и подробно опишите свою проблему.

## 3. Спросите у сообщества

Сообщество embedded Rust очень активно в Matrix-чатах. Matrix — это открытая децентрализованная сеть для безопасного обмена сообщениями.

Вот несколько полезных каналов Matrix по темам, которые затрагивает эта книга:

- **Embedded Devices Working Group**  
  [`#rust-embedded:matrix.org`](https://matrix.to/#/#rust-embedded:matrix.org)  
  Общие обсуждения использования Rust для разработки встраиваемых систем.

- **ESP32 Development**  
  [`#esp-rs:matrix.org`](https://matrix.to/#/#esp-rs:matrix.org)  
  Разработка на Rust для семейства чипов ESP32.

- **Debugging with Probe-rs**  
  [`#probe-rs:matrix.org`](https://matrix.to/#/#probe-rs:matrix.org)  
  Поддержка и обсуждение инструментов отладки [probe-rs](https://probe.rs).

- **Embedded Graphics**  
  [`#rust-embedded-graphics:matrix.org`](https://matrix.to/#/#rust-embedded-graphics:matrix.org)  
  Работа с [`embedded-graphics`](https://docs.rs/embedded-graphics), библиотекой для рисования во встраиваемых системах.

Вы можете создать аккаунт Matrix и присоединиться к этим каналам, чтобы получить помощь от опытных разработчиков.

Больше чатов сообщества можно найти в разделе [Awesome Embedded Rust - Community Chat Rooms](https://github.com/rust-embedded/awesome-embedded-rust?tab=readme-ov-file#community-chat-rooms).


## 4. Discord

Есть неофициальное сообщество embedded Rust в Discord, где можно задавать вопросы, обсуждать темы, делиться опытом и показывать свои проекты. Оно особенно полезно новичкам и для общих обсуждений.

Имейте в виду, что большинство мейнтейнеров HAL и участников embedded-экосистемы активнее в Matrix. Тем не менее этот Discord-сервер может стать хорошим местом, чтобы учиться и общаться с другими.

Присоединиться можно здесь: [https://discord.gg/NHenanPUuG](https://discord.gg/NHenanPUuG)
