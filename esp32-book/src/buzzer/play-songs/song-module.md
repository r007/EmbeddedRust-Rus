# Пример мелодии: тема Pink Panther (pink_panther.rs)

В этом разделе приведён код модуля `pink_panther` на Rust. Если нужны ноты других песен или фоновых мелодий, можете посмотреть репозиторий [Rust Embedded Songs](https://github.com/ImplFerris/rust-embedded-songs/).

### Темп
Здесь задаём темп песни (его можно изменить и посмотреть результат).

```rust
pub const TEMPO: u16 = 120;
```

## Массив мелодии
