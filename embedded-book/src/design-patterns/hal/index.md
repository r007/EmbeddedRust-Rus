# Паттерны проектирования HAL

Это набор общих и рекомендуемых паттернов для написания слоёв аппаратной абстракции (HAL) для микроконтроллеров на Rust. Эти паттерны предназначены для использования наряду с существующими [Rust API Guidelines] при написании HAL для микроконтроллеров.

[Rust API Guidelines]: https://rust-lang.github.io/api-guidelines/
