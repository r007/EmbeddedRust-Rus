# Начало работы

В этом разделе мы покажем, как писать, собирать, прошивать и отлаживать встраиваемые программы. Большую часть примеров можно попробовать без специального оборудования: основы мы покажем с помощью QEMU, популярного эмулятора аппаратного обеспечения с открытым исходным кодом. Единственный раздел, где оборудование действительно нужно, — это [Оборудование](./hardware.md), где мы используем OpenOCD, чтобы прошить [STM32F3DISCOVERY].

[STM32F3DISCOVERY]: http://www.st.com/en/evaluation-tools/stm32f3discovery.html
