# Шаблон проекта с `cargo-generate`

«cargo-generate — инструмент разработчика, который помогает быстро начать новый проект на Rust, используя существующий git-репозиторий в качестве шаблона».

Подробнее читайте на [странице проекта cargo-generate на GitHub](https://github.com/cargo-generate/cargo-generate).

## Требования

Прежде чем начать, убедитесь, что установлены следующие инструменты:

- [Rust](https://www.rust-lang.org/tools/install)
- [cargo-generate](https://github.com/cargo-generate/cargo-generate) для создания проекта из шаблона.

Сначала установите пакет разработки OpenSSL, так как он нужен cargo-generate:

```sh
sudo apt install  libssl-dev
```

Установить `cargo-generate` можно такой командой:

```sh
cargo install cargo-generate
```

## Шаг 1: создание проекта

Чтобы создать проект из шаблона, выполните команду:

```sh
cargo generate --git https://github.com/ImplFerris/pico2-template.git --tag v0.3.2
```

Команда задаст несколько вопросов:

- Имя проекта: укажите название проекта.
- Выбор HAL: можно выбрать `embassy` или `rp-hal`.

## Шаг 2: пример мигания светодиодом по умолчанию

По умолчанию проект создаётся с простым примером мигания светодиодом. Структура кода может выглядеть так:

`src/main.rs`: содержит стандартную логику мигания.

`Cargo.toml`: включает зависимости для выбранного HAL.

## Шаг 3: выбор HAL и изменение кода

После создания проекта можно оставить код мигания по умолчанию или удалить его и заменить своим — с учётом выбранного HAL.

## Удаление лишнего кода

Логику мигания из `src/main.rs` можно удалить и заменить своим кодом. При необходимости измените зависимости в `Cargo.toml` и структуру проекта.
