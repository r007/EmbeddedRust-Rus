# От std к no_std

Мы успешно прошили и запустили нашу первую программу, которая создаёт эффект мигания. Однако код и структуру проекта мы пока подробно не разбирали. В этом разделе мы воссоздадим тот же проект с нуля. По ходу дела я объясню каждую часть кода и конфигурации. Готовы к испытанию?

## Создаём новый проект

Начнём с создания стандартного бинарного проекта на Rust. Используйте следующую команду:

```rust
cargo new pico-from-scratch
```

На этом этапе проект будет содержать обычные файлы, как и ожидается.

```sh
├── Cargo.toml
└── src
    └── main.rs
```

Наша цель — получить следующую итоговую структуру проекта:

```sh
├── build.rs
├── .cargo
│   └── config.toml
├── Cargo.toml
├── memory.x
├── rp235x_riscv.x
├── src
│   └── main.rs
```
