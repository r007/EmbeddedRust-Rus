# Нелинейность термистора

Мы научились использовать термистор в делителе напряжения и вычислять сопротивление термистора в данный момент. Следующий шаг — определить температуру, соответствующую этому сопротивлению.

Этот шаг непростой. Термисторы — нелинейные устройства, то есть сопротивление меняется с температурой не по прямой. Поэтому пересчитать сопротивление в температуру с помощью одной линейной формулы нельзя.

## Проблема нелинейной кривой

Термистор меняет сопротивление неравномерно при изменении температуры. Зависимость между температурой и сопротивлением описывается кривой.

При низких температурах небольшое изменение температуры даёт большое изменение сопротивления. При высоких температурах то же изменение температуры даёт гораздо меньшее изменение сопротивления. Такое поведение — фундаментальное свойство термисторов.

Из-за этой кривой не существует простого правила вида:

фиксированное число омов соответствует одному градусу

## Использование известных опорных точек

Производители термисторов знают об этом поведении и публикуют подробные даташиты. В этих даташитах перечислены значения сопротивления при конкретных температурах.

Каждая запись в даташите представляет собой известную, измеренную точку на кривой термистора. Вместе эти точки описывают, как меняется сопротивление во всём диапазоне температур.

## Распространённые подходы на практике

Есть три широко используемых метода для перевода сопротивления термистора в температуру:

**Уравнение Бета (метод параметра B)**:

Этот метод использует одну константу материала, которая называется значением Бета. Значение приводится в даташите термистора. Метод предполагает, что кривую можно приблизить логарифмической зависимостью между сопротивлением и температурой.

**Уравнение Штайнхарта — Харта**:

Уравнение Штайнхарта — Харта — более точная модель кривой термистора. Вместо одной константы оно использует три коэффициента, которые лучше соответствуют нелинейному поведению.

Эти коэффициенты либо предоставляет производитель, либо получают из данных калибровки. Уравнение Штайнхарта — Харта обеспечивает высокую точность в широком диапазоне температур. Цена — больше вычислений и более сложная реализация.

**Таблицы поиска (lookup tables)**:

Таблица поиска хранит известные пары «температура — сопротивление». Эти значения берутся напрямую из даташита термистора или из калибровочных измерений. Когда измерено сопротивление, его сравнивают с таблицей, чтобы найти ближайшую подходящую температуру. Если сопротивление попадает между двумя записями, для оценки температуры между ними можно использовать интерполяцию.
