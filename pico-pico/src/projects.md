# Подборка проектов на Rust для Raspberry Pi Pico 2

Здесь собраны интересные проекты, которые я нашёл в интернете и которые связаны с Pico 2 и Rust. Если у вас есть интересный проект, которым хотите поделиться, пришлите PR :)

- [Pico Rex](https://github.com/ImplFerris/pico-rex): игра «Динозаврик» на Rust для Raspberry Pi Pico 2 (RP2350) с OLED-дисплеем, написанная на фреймворке Embassy.
- [GB-RP2350 — эмулятор Game Boy для Pi Pico 2 на Rust](https://github.com/Altaflux/gb-rp2350): также можно найти [пост автора на Reddit](https://www.reddit.com/r/raspberrypipico/comments/1h6hb3l/gbrp2350_a_game_boy_emulator_for_the_pi_pico_2/).
- [simple-robot](https://github.com/1-rafael-1/simple-robot): очень простой робот с ультразвуковым датчиком расстояния HC-SR04, который умеет двигаться как автономно, так и под дистанционным управлением (Rust, Embassy).
