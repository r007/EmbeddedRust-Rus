# Практический курс Rust

Русский перевод открытого учебного курса Rust, который [Tweede golf](https://github.com/r007/EmbeddedRust-Rus/tree/main/rust-training) использует для профессионального обучения. Курс охватывает основы языка, инженерию крейтов, многозадачность, веб, FFI, интеграцию с Python и встраиваемые системы.

Код, имена крейтов, команды и сообщения компилятора остаются на английском. Комментарии в примерах переведены.

> **Важно:** это учебные материалы, а не авторитетный справочник. Ключевые детали сверяйте с [официальной документацией Rust](https://doc.rust-lang.org/).

## Упражнения и слайды

Исходный код упражнений и слайды находятся в [репозитории оригинала](https://github.com/r007/EmbeddedRust-Rus/tree/main/rust-training). Пути вида `exercises/...` в тексте указывают на каталоги в этом репозитории. Здесь хранится только текст книги.

## Сборка

```bash
cargo install mdbook
mdbook serve --open
```
