# Вводный практикум

Этот практикум познакомит вас с основами разработки встраиваемых систем. К концу практикума мы научимся взаимодействовать с внешним миром, в том числе отправлять команды плате и получать данные с её датчиков. Программа включает:
- Обзор структуры проекта.
- Создание проекта с помощью `cargo-generate`.
- Написание HTTP-клиента.
- Написание HTTP-сервера.
- Написание MQTT-клиента, который:
  - публикует данные датчиков;
  - получает команды через подписку на топик.

 Пройдите главу [подготовки](./02_0_preparations.md), чтобы подготовиться к этому практикуму.
