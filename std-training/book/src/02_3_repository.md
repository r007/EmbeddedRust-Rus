# Репозиторий практикума

Весь материал находится по адресу <https://github.com/esp-rs/std-training>.

✅ Клонируйте репозиторий практикума и перейдите в его папку:

```console
git clone "https://github.com/r007/EmbeddedRust-Rus/tree/main/std-training"
cd std-training
```

❗ Пользователи Windows могут столкнуться с проблемами из-за [длинных путей][windows-long-path].

[windows-long-path]: https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation

## Содержимое репозитория

- `advanced/` — примеры кода и упражнения для продвинутого курса;
- `book/` — исходники этой книги в формате Markdown;
- `common/` — код, общий для обоих курсов;
- `common/lib/` — вспомогательные крейты;
- `intro/` — примеры кода и упражнения для вводного курса.


## Несколько слов о конфигурации

Во всём практикуме мы используем [`toml-cfg`](https://github.com/jamesmunns/toml-cfg) как более удобную и безопасную альтернативу тому, чтобы хранить учётные данные и другую чувствительную информацию прямо в исходном коде. Вместо этого настройки хранятся в файле `cfg.toml` в корне соответствующего пакета.

Эта конфигурация содержит ровно один заголовок секции, совпадающий с именем вашего пакета (`name = "your-package"` в `Cargo.toml`). Конкретные настройки будут различаться в разных проектах:

```toml
[your-package]
user = "example"
password = "h4ckm3"
```

❗ Если вы копируете `cfg.toml` в новый проект, не забудьте изменить заголовок на `[name-of-new-package]`.
